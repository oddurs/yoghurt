# Security Policy

## Supported versions

The project is pre-1.0. Only the latest release on `main` receives security
fixes.

| Version | Supported |
| --- | --- |
| 0.1.x | ✅ |
| < 0.1 | ❌ |

## Reporting a vulnerability

**Do not open a public issue.**

Report privately through GitHub Security Advisories:
<https://github.com/oddurs/yoghurt/security/advisories/new>

Include what you can — affected version, reproduction steps, and the impact you
believe it has. A proof of concept helps but is not required.

If GitHub is not an option, email <oddursusa@gmail.com>.

## What to expect

- **Acknowledgement** within 3 working days.
- **An initial assessment** — whether it is accepted, and a rough severity —
  within 7 days.
- **A fix or a plan** within 30 days for accepted reports. Complex issues may
  take longer; you will be told if so.
- **Credit** in the advisory and the changelog, unless you would rather not be
  named.

Please give the fix a chance to ship before disclosing publicly. This is a
volunteer project, so timelines are best effort rather than contractual.
